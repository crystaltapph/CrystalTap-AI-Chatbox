# CrystalTap Agent for Android

Download [CrystalTap-Agent-0.1.1.apk](CrystalTap-Agent-0.1.1.apk?raw=true) on an Android 8 or newer phone.

This is the signed native Android candidate build for approved CrystalTap staff. Update the WordPress plugin to version 0.2.1 before signing in. The website preset is https://crystaltapwater.com/.

Install this update over app 0.1.0 without uninstalling; it uses the same signing identity. This build adds system-displayed background notifications and delivery-delay diagnostics.

Remote alerts require your Firebase project to be configured in WordPress. Live notification delivery and audible alerts on a physical phone have not yet been verified. See the [installation and Firebase setup guide](../../docs/ANDROID.md).

`SHA256SUMS` verifies the downloaded APK. Private signing keys and credentials are not included. Future app updates must use the same signing identity.
